# Changelog

## v1.4.0
- Version is defined once in `version.js`; Settings shows it with a link to the matching GitHub release, and the offline cache follows it.
- GitHub tag and release are created automatically when the version changes.

## v1.3.0
- Beeps stay in sync with the intervals over long workouts (audio and system clock are re-aligned continuously).

## v1.2.0
- Fixed missing sound at the end of the workout; the finish now has its own three-note sound.

## v1.1.0
- One beep per transition (set end, rest end); countdown beeps are opt-in in Settings.

## v1.0.0
- First version: simple and advanced modes, ring countdown, saved workouts, stats, offline PWA.
